# SHIS

School Health Intelligence System. Parents open their child’s record. Medical staff record a visit. The system does not diagnose.

## Open in VS Code

Clone this repository, then File → Open Folder.

```
npm install
npm run dev
npm run api
```

Website: http://localhost:8080  
API: http://localhost:3001

VS Code tasks: **SHIS website** and **SHIS API**.

See [VSCODE.md](VSCODE.md).
